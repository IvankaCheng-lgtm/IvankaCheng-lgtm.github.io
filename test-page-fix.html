頁面切換問題修復

問題分析

任一個頁面點進去第二次都會變白畫面的問題，主要原因是在頁面切換時，代碼同時使用了兩種不同的方式來控制頁面的顯示和隱藏：

1. **CSS類控制**：使用 `classList.add('hidden')` 和 `classList.remove('hidden')`
2. **JavaScript樣式控制**：使用 `style.display = 'block'`、`style.display = 'flex'`、`style.display = 'none'`

這種混合使用導致了狀態衝突，特別是在第二次訪問同一頁面時，可能出現CSS類和內聯樣式不一致的情況。

修復方案

為了解決這個問題，我採取了以下措施：

1. **統一控制方式**：完全使用CSS類來控制頁面的顯示和隱藏，移除所有的 `style.display` 設置

2. **修改 `hideAllScreens()` 函數**：將 `screen.style.display = 'none'` 改為 `screen.style.display = ''`，移除內聯樣式

3. **清理所有頁面切換代碼**：移除了所有在顯示頁面時設置 `style.display = 'block'` 或 `style.display = 'flex'` 的代碼

4. **依賴CSS類**：完全依賴Tailwind CSS的 `hidden` 類和頁面元素的默認顯示樣式

修復的文件

index.html
- 修改了 `hideAllScreens()` 函數
- 清理了所有按鈕點擊事件中的 `style.display` 設置
- 確保頁面切換只依賴CSS的 `hidden` 類

測試方法

請按照以下步驟測試修復是否成功：

1. 打開應用首頁
2. 點擊底部導航欄的各個按鈕（首頁、營養分析、相機、歷史、AI建議）
3. 重複點擊同一個按鈕多次
4. 測試返回按鈕的功能
5. 驗證所有頁面在第二次及以後訪問時是否能正常顯示，不再出現白屏
