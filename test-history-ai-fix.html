🔧 歷史和AI建議返回功能修復

✅ 已修復的問題

歷史記錄頁面返回按鈕

修復了從歷史記錄頁面無法返回到首頁的問題。

AI建議頁面返回按鈕

修復了從AI建議頁面無法返回到首頁的問題。

🔧 根本原因分析

問題原因

  • 返回按鈕類名不一致：歷史記錄和AI建議頁面的返回按鈕使用了back-to-main-btn類名，而不是統一的back-btn
  • DOM重新創建導致事件丟失：這兩個頁面在每次顯示時都會重新設置innerHTML，導致之前綁定的事件監聽器失效
  • 事件委托機制失效：由於DOM元素被重新創建，事件委托機制無法正常工作

🛠️ 修復方案

1. 統一返回按鈕類名

將歷史記錄和AI建議頁面的返回按鈕類名從back-to-main-btn統一修改為back-btn。

2. 動態重新綁定事件

使用setTimeout確保在DOM更新後重新綁定事件監聽器：

// 重新添加返回按鈕事件（因為innerHTML會重新創建DOM元素）
setTimeout(() => {
    const backBtn = screen.querySelector('.back-btn');
    if (backBtn) {
        // 移除可能存在的舊事件監聽器
        const newBackBtn = backBtn.cloneNode(true);
        backBtn.parentNode.replaceChild(newBackBtn, backBtn);
        
        // 添加新的事件監聽器
        newBackBtn.addEventListener('click', function() {
            console.log('返回按鈕點擊');
            // 直接返回主頁
            hideAllScreens();
            mainScreen.classList.remove('hidden');
            mainScreen.style.display = 'block';
        });
    }
}, 100);

3. 移除舊事件監聽器

使用cloneNode方法移除可能存在的舊事件監聽器，避免事件重複綁定：

// 移除可能存在的舊事件監聽器
const newBackBtn = backBtn.cloneNode(true);
backBtn.parentNode.replaceChild(newBackBtn, backBtn);

4. 直接返回主頁

在返回按鈕事件中直接實現返回主頁的邏輯，不再依賴事件委托：

// 直接返回主頁
hideAllScreens();
mainScreen.classList.remove('hidden');
mainScreen.style.display = 'block';

🧪 測試步驟

1 歷史記錄頁面測試

  1. 從首頁點擊底部導航的「歷史記錄」按鈕
  2. 進入歷史記錄頁面後，點擊左上角的返回按鈕
  3. 應該正常返回到首頁

2 AI建議頁面測試

  1. 從首頁點擊底部導航的「AI建議」按鈕
  2. 進入AI建議頁面後，點擊左上角的返回按鈕
  3. 應該正常返回到首頁

3 多次切換測試

  1. 反覆切換進出歷史記錄和AI建議頁面
  2. 每次點擊返回按鈕都應該能正常返回主頁
  3. 檢查是否有事件重複綁定或其他異常
