🔧 返回按鈕空白頁面問題 - 最終修復

✅ 已徹底修復的問題

返回按鈕空白頁面問題

徹底解決了從首頁進入其他頁面後，點擊返回按鈕出現空白頁面的問題。

🔧 核心修復內容

1. 統一返回按鈕類名

將所有動態創建頁面中的返回按鈕類名從 back-to-main-btn 統一修改為 back-btn，確保所有返回按鈕都能被全局事件監聽器捕獲。

2. 增強全局返回邏輯

在全局返回按鈕事件處理器中添加了對所有動態創建頁面的檢測，包括：

  • 營養分析頁面 (nutrition-screen)
  • 個人資料頁面 (profile-screen)
  • AI建議頁面 (ai-advice-screen)
  • 歷史記錄頁面 (history-screen)
  • 食物庫頁面 (food-library-screen)

3. 事件委托機制

修改了各動態頁面的返回按鈕事件處理，不再使用獨立的事件處理邏輯，而是委托給全局返回按鈕處理器：

// 新的事件委托模式
backBtn.addEventListener('click', function() {
    console.log('頁面返回按鈕點擊');
    // 触发全局返回按钮逻辑
    const event = new Event('click');
    backButtons[0].dispatchEvent(event);
});

4. 默認返回保障

添加了默認返回主頁的邏輯，確保在任何情況下都不會出現空白頁面：

} else {
    // 默认返回主页
    mainScreen.classList.remove('hidden');
    mainScreen.style.display = 'block';
    console.log('默認返回主頁');
}
